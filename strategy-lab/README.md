# 早盘资金榜雷达（本地采集端）

这个目录只做一件事：每分钟采集同花顺「个股资金流」按**主力净流入额降序**排列的第一页 50 只股票，并上传到慢富页面。

它不连接券商、不自动下单、不计算研究分，也不把上榜次数包装成“稳赢”或涨停预测。

## 页面会展示什么

- 当天出现过的股票，按**上榜次数降序**排列；页面同时显示“上榜次数 / 当日成功快照次数”和对应频率，同次数按最近一次榜单名次排列。
- 最近一次出现时的价格、涨跌幅、所属分板、申万行业和最多三个同花顺概念。
- 按分板给出的涨幅追高风险提示：主板 5% / 8%，创业板、科创板和北交所 9% / 14% 分别为提醒 / 高风险线。
- 最近一份原始 50 条榜单快照及采集时间，方便回看和核对。

行业与概念来自上榜股票的同花顺基础资料页，缓存 30 天；它们不参与筛选，也不会阻塞个股榜采集。

## 手动运行

```powershell
node .\strategy-lab\collector.mjs
```

为保护统计口径，采集器只会在交易日 09:30–10:30 上传。盘外需要验证网页时，可以明确使用 `node .\strategy-lab\collector.mjs --force`；这会产生测试快照，不应当用来判断当天的上榜次数。

本地会在 `local-data/flow-lab/flow-lab.sqlite` 和按日期的 JSONL 中保留原始快照。只有同时配置好 `FLOW_LAB_API_URL` 和 `FLOW_LAB_INGEST_TOKEN` 时，结果才会上传到慢富线上页面。

## 无窗口自动采集

```powershell
.\strategy-lab\register-task.ps1
```

该命令会创建/更新 Windows 任务 `Manfu-FlowLab-Collector`：每个交易日 09:30 开始，每分钟运行一次，10:30 结束。任务通过 `wscript.exe` 启动 Node，不会弹出 Node 控制台窗口。

## 历史数据清理

默认自动保留最近 10 个有成功快照的交易日。采集器会在每个新交易日首次成功上传后调用线上清理；本地原始 SQLite 快照也按同样天数裁剪。可以用环境变量 `FLOW_LAB_RETENTION_DAYS` 调整到 3–60 天。

慢富页面的管理员可选择保留 5 / 10 / 20 个交易日，并通过“清理历史”按钮立即执行；按钮会要求二次确认。清理只影响早盘资金榜模块的快照、候选记录及旧纸面记录，不影响筑基看板、BTC 周期灯塔或其他业务数据。

## 数据边界

- 数据源仅为同花顺公开个股资金榜；页面结构或反爬规则变化时，本轮会标记失败，失败轮次不计入上榜次数。
- 页面里的“实时刷新”和“刷新快照”只重新读取慢富已上传的数据，不会从浏览器触发采集。
- 上榜次数只表示一只股票在短时间内持续出现在净流入榜前 50；它不包含成交量、盘口、公告、估值、市场环境或次日流动性，因此不能单独作为交易依据。
